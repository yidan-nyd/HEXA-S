# HEXA-S 验证框架

| 维度 | 核心问题 | 示例指标 / 证据 |
| --- | --- | --- |
| 传感重复性 | 同一拉伸是否得到相近结果 | 多循环误差、回程差、方差 |
| 漂移与迟滞 | 长时间与反复加载后是否偏移 | 多时段漂移、恢复时间 |
| 环境稳健性 | 温湿度、洗涤、穿脱是否影响结果 | 分条件测试、重新标定频率 |
| 空间映射 | 通道是否对应正确身体区域 | 单区拉伸混淆、通道串扰 |
| 几何有效性 | 相对信号能否对应真实形变 | 与卷尺、扫描或标准治具对照 |
| 实时性能 | 采集到显示是否稳定 | 帧率、端到端延迟、丢帧率 |
| 佩戴体验 | 是否舒适且不限制活动 | 舒适量表、压点、穿脱时间 |
| 数据质量 | 错误是否被识别并说明 | 故障检出率、恢复成功率 |
| 模式识别 | 是否发现趋势且不过度告警 | 灵敏度、特异度、假阳性、校准度 |
| 解释与理解 | 用户能否理解依据与限制 | 复述准确率、误解案例 |
| 临床可用性 | 是否改善判断而非增加负担 | 任务时间、决策一致性、访谈 |
| 人工控制 | 能否修改、拒绝、暂停与接管 | 接管成功率、撤回路径、日志 |
| 隐私与治理 | 是否按同意范围使用数据 | 权限、保留与删除测试 |
| 真实结果 | 是否改善舒适度与适配过程 | 不适频率、调整次数、长期反馈 |

## 建议顺序

1. 标准治具上的材料与传感器测试；
2. 穿戴结构与电子系统工程测试；
3. 在适当审批下开展健康志愿者可用性测试；
4. 假肢使用者与技师探索性研究；
5. 锁定算法后进行前瞻性临床验证；
6. 按法规、风险管理与质量体系要求评估产品化。
