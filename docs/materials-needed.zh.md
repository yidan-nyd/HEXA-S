# HEXA-S 发布与验证素材清单

## 网站优先补充

- 真实佩戴主视觉，以及织物、电子系统与 3D 模型同框画面；
- 10–15 秒端到端视频：局部拉伸与对应模型同步变化；
- 单传感器 → 双传感器 → 六点环 → 之字网络的原型演化；
- 传感点、身体区域、通道编号和 3D 对象的一一映射图；
- 原始数据、滤波数据和归一化数据对比；
- TPU 晶格样件及材料属性差异；
- 团队分工与个人贡献的准确说明。

## GitHub 优先补充

- `LICENSE` 与第三方依赖归属；
- 电路图、接线照片与 BOM 型号；
- Blender 示例文件或最小场景；
- 可匿名公开的示例串口数据；
- 每件织物样品的标定模板；
- 通道—身体区域—Blender 对象映射模板；
- 重复性、迟滞、漂移与串扰测试；
- 端到端演示 GIF / 视频和已知限制；
- 固件版本、Blender 版本与复现环境。

## 获得证据前不要写成已实现

- 精确残肢尺寸测量；
- 临床级数字孪生；
- 健康风险诊断；
- 经临床验证的假肢适配建议；
- 自动生成并投入使用的接受腔 / 晶格结构；
- 长期佩戴可靠性和真实患者疗效。
